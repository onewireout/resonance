# Resonance

A Wayland desktop I built for myself: a wlroots compositor in C (`compositor/`) and a hub plus window placement logic in Go and Python (`core/`).

## Credit

The compositor started from [TinyWL](https://gitlab.freedesktop.org/wlroots/wlroots/-/tree/master/tinywl), the example compositor from the wlroots project. Its license is in `compositor/LICENSE`.
